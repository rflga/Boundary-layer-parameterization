This repository contains the LES outputs generated by the models MicroHH and Oceananigans, used in the paper "Towards a Unified Data-Driven Boundary Layer Momentum Flux Parameterization for Ocean and Atmosphere
"

The files in Atmos_outputs contain the atmospheric LES outputs, denoted as UgXQYYYqZZ, with X being the value of geostrophic wind (Ug) used in the simulation, YYY the surface heating (Q) and ZZ the initial water vapor mixing ratio (q)
