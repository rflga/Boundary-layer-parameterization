This repository contains the LES outputs generated by the models MicroHH and Oceananigans, used in the paper "Towards a Unified Data-Driven Boundary Layer Momentum Flux Parameterization for Ocean and Atmosphere
"

The files in Atmos_outputs contain the atmospheric LES outputs, denoted as UgXQYYYqZZ, with X being the value of geostrophic wind (Ug, in m/s) used in the simulation, YYY the surface heating (Q, in K.m/s) and ZZ the initial water vapor mixing ratio (q, in g/kg). 
Each file contains the variables "u", "v", "u_flux" and "v_flux", corresponding respectively to the zonal wind, meridional wind, and components of the subgrid momentum fluxes (u'w' and v'w').

The files in Ocean_outputs contain the oceanic LES outputs, denoted as UXHFYYY, with X being the value of the surface wind forcing (U, in m/s) and YYY The value of the surface cooling (HF, in W/m2). The oceanic files contain the same variables as the atmospheric files. When "_LM" is included in the file name, it corresponds to a simulation where Langmuir circulation was included.
